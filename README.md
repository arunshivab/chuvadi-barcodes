# Chuvadi.Barcodes

**Pure .NET 10 barcode and QR code library — encode and decode every major open 1D and 2D
symbology. Zero dependencies. Part of the Chuvadi family.**

> **Status: under construction (0.x).** QR Code, Micro QR and structured append can be
> **encoded** and rendered to SVG/PNG. Decoding arrives in M4. See the [roadmap](#roadmap).

## Quick start

```csharp
using Chuvadi.Barcodes.Encoders;
using Chuvadi.Barcodes.Rendering;

QrSymbol qr = QrEncoder.Encode("https://example.org");
string svg = SvgRenderer.Render(qr.Matrix);
byte[] png = PngRenderer.Render(qr.Matrix, new RasterRenderOptions { ModuleSize = 8 });
```

Command line (from the repo):

```
dotnet run --project examples/Chuvadi.Barcodes.Cli -- encode --format qr --data "Hello" --out hello.png
```

## Implemented so far

| Symbology | Encode | Decode | Verified against |
|-----------|:------:|:------:|------------------|
| QR Code Model 2 (v1–40, L/M/Q/H, all modes, ECI, GS1, Kanji) | ✅ | M4 | Zint (module-for-module), ZXing.Net (round trip) |
| Structured append (QR) | ✅ | M4 | Zint, ZXing.Net |
| Micro QR (M1–M4) | ✅ | M4 | Zint (module-for-module) |

## Building

```bash
dotnet build Chuvadi.Barcodes.slnx
dotnet test Chuvadi.Barcodes.slnx
```

Requires the .NET 10 SDK (pinned in `global.json`).

## How correctness is checked

No ISO specification is used. Every encoder is compared module-for-module against golden
fixtures generated by [Zint](https://zint.org.uk), and QR symbols are decoded by
[ZXing.Net](https://github.com/micjahn/ZXing.Net) in round-trip tests. Both are **test-only**
tools: the published packages have no external dependencies.
